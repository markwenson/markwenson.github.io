Slack Attendance Status

A compact Slack-to-API workflow that parses human-readable status text into a normalized value and sends it to an internal endpoint.

SlackJavaScriptHTTP APIn8n

Problem

Human-entered status messages are not always in a format that downstream systems can consume directly.

Solution

The workflow listens for a Slack event, parses and maps the text into a structured status, then sends the normalized value through an HTTP request to the destination system.

Why this matters

Small workflows can still demonstrate useful engineering skills when they solve a clear interface problem between human input and a structured system.
